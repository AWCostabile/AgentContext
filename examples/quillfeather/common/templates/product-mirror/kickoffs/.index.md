# {{Product Name}} kickoffs

The launch prompts of each plan's work, one leaf per plan
(`kickoffs.<YYYY-MM>-<n>.<slug>.md`), grouped under the plan's month (`YYYY-MM/`). A prompt is
rewritten in place until an agent has run from it; from then on it is frozen, because that agent
was launched from it verbatim, and the next prompt goes below it.
