# Tillwright PR appendices

Audit tables that back a PR body (a correction inventory, a disposition table), filed beside the
bodies rather than among them, grouped under the plan's month (`YYYY-MM/`). Each leaf is
`<form>.<YYYY-MM>-<n>.<slug>.md` (`closeout.`, `dispositions.`), manifest kind `appendix`, and opens by
naming the body it accompanies. Never `pr.`-prefixed. Added verbatim, never edited.
