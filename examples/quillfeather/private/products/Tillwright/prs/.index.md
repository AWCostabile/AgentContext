# Tillwright PR bodies

One impersonal codebase record per pull request, added verbatim, grouped under the plan's month
(`YYYY-MM/`). Named `pr.<YYYY-MM>-<n>.<branch-slug>.md`: the plan's number, then the branch name with
its type prefix dropped and its PascalCase kebabbed. It opens with `_branch:_ <type>/<Name>` under the
H1. It stays editable until its pull request lands, then freezes. Bodies only: audit tables go in
[Tillwright PR appendices](../appendices/.index.md).
