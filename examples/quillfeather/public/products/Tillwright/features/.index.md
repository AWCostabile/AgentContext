# Tillwright feature log

What is true of Tillwright today, one leaf per AREA of the product (`features.<area>.md`): a
**State today** paragraph kept current, then dated entries newest first under ISO-week headers. No
process vocabulary, and links into `public/` only. Each row names the area's headline features, so
index-line search finds them.
