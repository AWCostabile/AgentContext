# Tillwright glossary

One entry per term, as each is settled; a term's law lives in the design leaf it links to.

- **available** — on hand minus the copies held for customer orders. See [the stock ledger](./design/design.stock-ledger.md).
- **customer order** — a request for a title the shop does not hold: it reserves the first matching copy received and holds it for fourteen days. See [customer orders](./design/design.customer-orders.md).
- **hold** — a copy reserved for a customer order, kept fourteen days and then returned to the shelf. See [customer orders](./design/design.customer-orders.md).
- **movement** — one line of the stock ledger: a receipt, a sale, a return, a transfer or an adjustment; every count the product shows is computed from them. See [the stock ledger](./design/design.stock-ledger.md).
- **sale number** — the till's letter, the date and a counter (`B-20261030-0042`), made on the till, so a receipt is valid before the ledger has seen the sale. See [the till](./design/design.till.md).
- **till** — the counter screen: it scans books, takes payment and prints the receipt, and keeps selling when the connection drops. See [the till](./design/design.till.md).
