# Products

The products catalog: what we sell to bookshops, one branch per product, each a copy of
`templates/product`. A catalog is one of the top-level buckets named in `.conf`'s `CATALOGS`.

## Contents

| File | Purpose |
| ---- | ------- |
| [Tillwright](./Tillwright/.index.md) | point of sale and stock for independent bookshops: the till, the stock ledger, customer orders |
| [Spinecard](./Spinecard/.index.md) | printed recommendation cards for the shelf, from titles Tillwright holds |
