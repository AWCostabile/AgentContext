# House vocabulary

The words the team uses in conversation, in tickets and in this tree, with the one meaning each
has here. A word a customer uses differently is noted.

| Word | Means here |
| ---- | ---------- |
| shop | one customer business, whatever its number of premises |
| branch | one premises of a shop; a shop with two premises has two branches (never a git branch in support tickets: say "code branch") |
| till | one counter machine running Tillwright, with its card terminal beside it |
| title | a book as an edition: one ISBN, or one shop-local code |
| copy | one physical book of a title |
| on hand | copies on the premises, reserved ones included |
| available | on hand minus the copies held for customer orders |
| hold | a copy reserved for a customer order, kept for fourteen days |
| card | a Spinecard recommendation card; never a payment card, which is "bank card" in writing |
| trial | the free thirty-day period a shop starts from the website's trial form |

Shops call a customer order a "special order" or a "put-by"; the product and this tree say
"customer order" throughout.
