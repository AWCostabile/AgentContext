# Process Templates

Copy these rather than writing a process document by hand, and replace every `{{ }}`
placeholder and the template's own comment.

## Contents

| File | Purpose |
| ---- | ------- |
| [Kickoff template](./kickoff.md) | the paste-ready first prompt of an orchestrated wave, with its guidance comment and a fictional example |
| [Code-standards template](./code-standards.md) | one product's commit subjects, branches, pull requests, change log, gates and review loop, as a form to fill into the product's design tier |
| [Bill template](./bill.md) | one plan's prospective law, filed in `constitution/bills/` or a product's `bills/` branch as `bill.<YYYY-MM>-<n>.<slug>.md`, with its guidance comment |
| [Bills-branch template](./bills.index.md) | the `.index.md` of a `bills/` branch, with the five bill columns |
| [Open-questions ledger](./questions.md) | `private/journal/ledgers/questions.md`: one dated line per open question and where it ripens, struck when answered |
