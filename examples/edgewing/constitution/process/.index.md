# Process

The process half of the constitution: how orchestrated work is briefed, launched, run and
closed, written as instructions for each reader. Each file cites the article it implements, and
every rule in a ground-rules file names its seed ruling or its open bill, so editing one is an
amendment. A product's code standards are filled from the code-standards form in `templates/`
into the product's own design tier, `design.code-standards.md`; Winchbook's is written.
