# House vocabulary

The words the team uses in conversation, in tickets and in this tree, with the one meaning each
has here. A word a club uses differently is noted.

| Word | Means here |
| ---- | ---------- |
| club | one customer: a gliding club, however many airfields it flies from |
| field | one airfield a club flies from; never a form field, which is "input" in writing |
| launch point | the end of the field where the queue and the tablet are |
| tablet | the one device at the launch point running Winchbook |
| line | the queue of one launch method for the day |
| tug | the tow plane of an aerotow launch; clubs also say "the tow" |
| flying day | from the first launch to the last landing; the log is kept per flying day |
| member | a person in the club's membership list, flying or not |

Clubs call the flight log "the launch sheet" or "the daily return"; the product and this tree say
"the day's log" throughout.
