# Journal

The work ledger of this machine. [Latest](./latest.md) is the status page (the active work): in flux,
last landed, next open, unpushed branches. It is rewritten as work moves and stays at the root.
[Inbox](./inbox.md) is the one cheap landing for a thought mid-session. Five branches hold the rest. A
new month's first filing creates its month branch (`YYYY-MM/`, with its own `.index.md` and `.tags`)
and its row in the parent's Contents.

## Contents

| File | Purpose |
| ---- | ------- |
| [Latest](./latest.md) | the status page: in flux, last landed, next open, unpushed branches; rewritten as work moves |
| [Inbox](./inbox.md) | the landing for a thought mid-session: append-only dated lines under Mine and Candidates, each promoted (filed properly) or dropped when triaged; an item past 14 days is a smell |
| [Journal Entries](./entries/.index.md) | the dated landing entries, one per finished piece of work, grouped by month |
| [Epics](./epics/.index.md) | the cross-product epics: the ordered rows of plans a block of work runs through |
| [Ledgers](./ledgers/.index.md) | the roadmap, the drift ledger and any later cross-product ledger |
| [Retrospectives](./retros/.index.md) | retrospectives over blocks of landed work, grouped by month; immutable |
| [Reflections](./reflections/.index.md) | a session's own account of the process, grouped by month; append-only |
