# From 0.5.0

Nothing moves between `v0.5.0` and the release after it, so no file is kept at an old name and nothing is left to you but a `kept` file you edited yourself. As in every update, the deployer deletes only a file whose bytes equal a hash it holds (the recorded one on an update, the release's on an adoption) and the root manifest it has just rewritten under `common/`; nothing else, ever.
