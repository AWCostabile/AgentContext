# From 0.5.1

Two directories arrive between `v0.5.1` and the release after it, and nothing moves. The reference branch, `common/reference/`, is laid with its index, and the refusal table that closed `SETUP.md` becomes its leaf `common/reference/refusals.md`; the staging directory, `common/staging/`, is laid as its `.gitignore` alone, a working directory that ignores its own contents. No file is kept at an old name, so nothing is left to you but a `kept` file you edited yourself. As in every update, the deployer deletes only a file whose bytes equal a hash it holds (the recorded one on an update, the release's on an adoption) and the root manifest it has just rewritten under `common/`; nothing else, ever.
