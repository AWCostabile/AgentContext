# Scripts

The tree's own tools: search and the two layers of the linter. Run them from the root
(`bash common/scripts/cure.sh`); each takes `--root <dir>` to work on another tree. They read `.conf`
for the catalogs and the private scopes, and treat an absent `private/` as normal.
[HYGIENE.md](../HYGIENE.md) is the contract of every check they make.

## Contents

| File | Purpose |
| ---- | ------- |
| `cure.sh` | the structural linter: it fails on a broken invariant (a missing index or tags, an orphan, a dead link, a public link into the private tree); `--fast` skips the advisory scans; the exit code is the fail count |
| `smell.sh` | the heuristic smells: what is probably wrong and needs judgement, one warning each; `--quiet` prints the summary only; the exit code is the smell count |
| `find.sh` | tag and keyword search: tags resolve to ranked branches, each labelled with its tree; `-x` expands a branch, `-l` lists the tag vocabulary, `-k` greps index lines, `-b <leaf>` lists the files that cite a leaf (its index row marked), `-f <key>` lists the files carrying a `_<key>:_` marker line with its value (`=`, `<`, `>` compare it), `-p` searches all of `private/` |
| `review.sh` | the review agenda, about thirty lines and nothing written: the linter verdict, the smell summary, the inbox, the open questions (when the journal keeps the ledger), the stale and uncited leaves, the retro pressure, the branches without an upstream, the newest journal entry; `--brief` one line of counts; the exit code is the fail count of `cure.sh` |
| `lib-scopes.sh` | shared resolution of which trees and private branches are in scope, read from `.conf`; sourced by the three scripts, never run |
| `lib-manifest.sh` | shared parsing of provenance manifests (the Contents tables with a "Landed as" column) and the newest retrospective; sourced, never run |
| `retired-terms.txt` | the vocabulary the smell linter refuses in live documents, one `term<TAB>replacement<TAB>source` line each; add a line when a spelling is retired |
