# Reflections

A session's own account of the process: how the work felt to run, what in the tooling and rules helped
or hurt, how well the tree oriented the session that read it. One leaf per occasion
(`reflection.YYYY-MM-DD.<slug>.md`), grouped by month (`YYYY-MM/`), rows newest first. Append-only: a
later reflection may disagree with an earlier one, never edit it.
