# {{Catalog}} — private mirror

A placeholder, mirroring the public branch of the same name with its development-cycle records.
There is one of this branch per entry in `.conf`'s `CATALOGS`, named after that entry. What is
true of a product lives in the public branch: [{{Catalog}}](../../public/{{catalog}}/.index.md).
Copy `templates/product-mirror` here once per product, under the same path `public/` uses
(`<catalog>/<Name>/`), and fill in every placeholder.
