# Private — the development cycle on this machine

Read [`.agent`](./.agent) first. `public/` is company knowledge; this tree is how the work was run,
as known on this machine: plans, kickoffs, PR bodies, retros, epics, ledgers. It mirrors the product
branches of `public/` under the same branch grammar, is a git repository of its own (trunk only, one
commit per filing action), and links into `public/` freely, never the reverse.

## Contents
