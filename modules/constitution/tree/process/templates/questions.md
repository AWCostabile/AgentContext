# Open questions

What is not yet known and is worth asking again: each question, and where it will ripen.

An open question is one line, `- YYYY-MM-DD — <question> — <where it ripens: a bill, a spike, a person>`,
dated the day it was asked. An answered question is the same line struck and dated,
`- ~~YYYY-MM-DD — <question> — <where it ripens>~~ answered YYYY-MM-DD`; it is never deleted.
