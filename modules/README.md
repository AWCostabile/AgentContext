# Modules

Optional additions, adopted or deleted per instance. `init.sh --adopt <module> --target <instance>` lays a module at its place and records it in the instance's manifest, so `--update` refreshes it file by file as it does the core. The core never depends on one, and no module names an agent harness.

| Module | What it adds |
| ------ | ------------ |
| [Constitution](./constitution/README.md) | the tree's law about itself: seed rulings, articles that cite them, a place for bills, and the process half (a kickoff guide, ground rules for each reader of an orchestrated piece of work, a code-standards template). Adopt it with `init.sh --adopt constitution`, which lays `tree/` at the instance's `constitution/`, and prune it; delete it if the core's `common/rules/` are enough. |
| [Codebase](./codebase/README.md) | a generated code map of a product's repository: one command writes `codebase/` under the product's branch (its source areas, the surfaces it exposes, and one symbols leaf per area, every location a `path:line`), with a TypeScript and a Go extractor, a `--check` drift gate and a fixture check. Adopt it with `init.sh --adopt codebase`, which lays it at the instance's `common/modules/codebase/`; Python 3.10+ is all it needs. |
| [Change log](./change-log/README.md) | a GitHub Actions workflow that rewrites every merged pull request into one squash commit, a bubble merge and a `CHANGE_LOG.md` entry built from the pull request's title and its commit subjects. Adopt it by copying `post-merge.yml` to a repository's `.github/workflows/` and adding one secret (the one module `init.sh --adopt` refuses, since it belongs to a repository, not the tree); this repository runs the same copy on itself. |
| [Graphify](./graphify/README.md) | one Graphify knowledge graph per repository, kept as a generated `graphs/` tier at the instance root: `home` links a repository's `graphify-out` into the tree (a junction on Windows, a symlink elsewhere) and seeds its ignore files, `scan` rebuilds each graph offline and commits one snapshot, `check` reports links, pin, staleness and drift. Adopt it with `init.sh --adopt graphify`, which lays it at the instance's `common/modules/graphify/`, and name the repositories in `.conf`; bash and the `graphifyy` tool are all it needs. |
| [Context retention](./context-retention/README.md) | a per-clone identity every project in the workspace carries, `.agents/.id.meta` (an id, a name, a date, never a path; never committed), so an agent can keep a project's memory and history when the folder moves: `init` mints it and asks once to ignore it in git's global excludes, `check` reports a moved or copied project against the map in the user's home, `list` prints the map. The instance's `AGENTS.md` carries the first-touch rule the file serves; an adapter turns a reported move into its harness's repair. Adopt it with `init.sh --adopt context-retention`, which lays it at the instance's `common/modules/context-retention/`; bash is all it needs. |
